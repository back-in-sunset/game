**更新时间**：2026-05-09
**基于**：`docs/product/attention.md` 商业化分析
**目标**：将商业化路线图转化为三个清晰的产品形态，每个形态有独立的产品定位、目标用户、功能边界和成功指标。

```

┌──────────────┐          ┌──────────────┐          ┌──────────────┐
```

三个形态不是三个独立产品，而是**同一个产品的三次蜕变**。每次蜕变保留上一阶段的核心能力，叠加新的产品层级。

## 近期：开发者工具（Game Backend Cloud — Developer Edition）

### 产品定位

一个面向独立游戏开发者的**免费实时后端工具**，5 分钟接入，提供 IM 长连接和语音信令能力。

一句话：**"游戏后端的 Vercel —— 打开浏览器就能用的 IM + 语音服务。"**

### 目标用户画像

- 团队规模：1-5 人
- 技术栈：Unity / Cocos / UE / Web 小游戏
- 游戏类型：休闲/棋牌/IO/社交
- 痛点：没有后端人力，但需要 IM 和语音
- 当前方案：Firebase + 自己拼凑 / 腾讯云 IM（嫌贵/嫌重）

### 核心功能

| 模块 | 包含 | 不包含 |
|------|------|--------|
| IM | WebSocket 接入、单聊消息、离线补发、会话列表 | 群聊、已读回执、消息搜索 |
| 语音 | 1v1 通话、多人房间（分享 URL）、LiveKit 接入、token 签发 | 通话录制 |
| 用户 | 注册/登录、JWT 鉴权 | OAuth、手机验证码 |
| 好友 | 添加/删除/列表、在线状态 | 分组、黑名单、备注 |
| SDK | Web SDK（npm 包）、REST API 文档 | Unity/Cocos SDK、原生 iOS/Android SDK |
| Demo | 公开可访问的 SPA demo（只读 token 内嵌）| — |

### 关键交付物

1. **公开 Demo 页面**：打开即玩，IM 聊天 + 语音通话，无需登录
2. **3 篇技术文章**：IM 协议设计 / LiveKit 实践 / 微服务拆分
3. **Web SDK npm 包**：`@gamecloud/web-sdk`，含 IM 客户端 + LiveKit helper
4. **接入文档**：中英双语 README，从零到消息收发的 5 分钟教程
5. **开发者社区**：Discord/飞书群，亲自回答每个问题

### 成功指标

- 注册开发者 ≥ 100
- 周活跃开发者 ≥ 30
- SDK 接入成功率 ≥ 60%（从注册到首条消息收发）
- GitHub stars ≥ 500

### 不做什么

- 不做付费墙（全部免费）
- 不做 Unity/Cocos SDK（只有 Web SDK + REST API）
- 不做群聊/频道（保持 IM 简单）
- 不做内容审核后台
- 不做移动端 App（Web 优先）

### 进入下一阶段的信号

- 月活跃开发者 ≥ 200 且自然增长占比 ≥ 50%
- 有 ≥ 5 个开发者主动询问"能支持更多 MAU 吗？"或"能付费吗？"
- 至少 1 个开发者将产品用于线上游戏（非本地调试）

## 中期：社区平台（Game Backend Cloud — Community Edition）

### 产品定位

在实时后端之上叠加**游戏社区层**（动态/攻略/评论），社区内容吸引玩家流量，玩家流量反哺开发者入驻，形成双边网络效应。实时能力（语音/IM）开始收费。

一句话：**"游戏开发者的 Firebase + Discord —— 后端能力 + 社区运营一站式。"**

### 目标用户

- **开发者侧**：同上，但从免费升级为付费
- **玩家侧**（新增）：开发者所服务游戏的终端玩家，通过社区内容进入平台

### 核心功能（在近期基础上叠加）

| 模块 | 新增 | 不包含 |
|------|------|--------|
| IM | 群聊/频道、已读回执 | — |
| 语音 | 多人语音房间、语音分钟数计费 | 视频通话 |
| 社区 | 动态 feed、攻略、评论、点赞、话题 | 推荐算法 |
| 运营 | 内容审核后台、公告推送 | — |
| 平台 | 项目管理（多游戏接入）、API Key 管理 | 租户隔离、RBAC |
| 计费 | 语音分钟数套餐、存储超额计费 | 复杂阶梯定价 |
| SDK | Unity SDK、Cocos Creator SDK | UE SDK |

### 产品套餐

| 套餐 | 月费 | 核心限制 |
|------|------|---------|
| 免费版 | ¥0 | 500 MAU、5GB 存储、1 万条消息/天、单项目 |
| 基础版 | ¥299/月 | 5000 MAU、50GB 存储、3 个项目 |
| 专业版 | ¥1999/月 | 5 万 MAU、语音 1 万分钟、10 个项目 |

### 推广策略

- **案例驱动**：找 3-5 个小团队深度使用，产出案例文章 + 数据对比
- **Game Jam 赞助**：提供免费专业版，覆盖种子用户
- **邀请机制**：免费用户每人 3 个邀请码，升级赠送 14 天专业版
- **不投 SEM**：开发者不点广告，CAC 太高

### 成功指标

- 付费客户 ≥ 50
- MRR ≥ ¥50,000
- 月流失率 ≤ 5%
- 语音分钟数月消耗 ≥ 100 万分钟

### 进入下一阶段的信号

- MRR ≥ ¥10 万且月增长 ≥ 15%
- 有 ≥ 3 个发行商/工作室询问企业版功能（私有化部署、SLA）
- 单一客户愿意支付 ≥ ¥5 万/年

## 远期：B2B SaaS 平台（Game Backend Cloud — Enterprise Edition）

### 产品定位

完整的**多租户游戏后端 SaaS 平台**，面向工作室和发行商，支持私有化部署、SLA 保障、定制化集成。

一句话：**"游戏行业的 AWS GameLift + PlayFab 替代品，但更轻、更便宜、更懂小团队。"**

### 目标用户

- 中型游戏工作室（20-100 人）
- 游戏发行商（管理多款游戏）
- 地方棋牌/社交运营商

### 核心功能（在中期基础上叠加）

| 模块 | 新增 |
|------|------|
| 平台 | 多租户隔离（Tenant/Project/Environment）、RBAC 权限体系、配额管理 |
| 配置 | 配置中心（继承/覆盖/发布/回滚）、多环境管理 |
| 计费 | 完整计费系统（按 MAU/存储/语音/连接数）、发票、对公转账 |
| 部署 | 私有化部署方案、SLA 99.9%、专属技术支持 |
| 游戏 | 房间管理、匹配服务（Phase 3 游戏运行层首次落地） |
| 安全 | 审计日志、审批流、高风险操作二次确认 |

### 产品套餐

| 套餐 | 定价 | 核心差异 |
|------|------|---------|
| 专业版 | ¥1999/月 | 云托管，共享资源 |
| 企业版 | 议价（¥5-20 万/年） | 私有化部署、SLA 99.9%、专属技术支持、定制集成 |

### 成功指标

- 企业客户 ≥ 10
- MRR ≥ ¥300,000
- 单一最大客户收入占比 ≤ 30%
- 净收入留存率（NRR）≥ 100%

## 贯穿三态的约束

### 不变的东西

1. **核心技术栈**：Go + go-zero + MySQL + Redis + etcd，不引入新技术栈
2. **IM 协议**：自定义二进制帧，不切 STOMP/MQTT
3. **语音方案**：LiveKit WebRTC，不自研媒体服务器
4. **开发者体验优先**：从近期到远期，DX 始终是差异化竞争力

### 每个阶段不做什么（防止范围膨胀）

| 阶段 | 不做什么 |
|------|---------|
| 近期 | 不收费、不做 Unity SDK、不做群聊、不做移动端 |
| 中期 | 不做视频、不做 UE SDK、不做私有化部署、不做 AI 推荐 |
| 远期 | 不做自研游戏引擎、不做游戏发行业务、不做反外挂 |

### 风险对冲

| 风险 | 应对 |
|------|------|
| 大厂推出同类低价产品 | 坚持 DX + 社区差异化，不做价格战 |
| 无人付费 | 免费 tier 放高，先保用户量再调价格 |
| 语音成本失控 | 语音单独计费，不做无限量套餐 |
| 合规风险 | 初期只做技术平台，不碰游戏内容运营 |
